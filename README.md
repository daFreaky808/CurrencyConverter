# Currency Converter
- A simple web app that converts between currencies using real-time exchange rates.

# Features
- Convert between All currencies
- Real-time exchange rate data via ExchangeRate-API
  
# Tech Stack
- Backend: JavaScript
- Frontend: HTML, CSS, JavaScript
- API: ExchangeRate-API https://www.exchangerate-api.com/
 
# What I learned
- Built this to practice working with external APIs and handling backend logic independently. I learned how to structure the conversion logic between different rates, and error handling for invalid inputs.
